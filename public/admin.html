Assign the administrator profile

Identity role: admin
  1. Open the VeilFarers project in Netlify and go to Project configuration → Identity → Users.
  2. Select the Identity user who should administer the portal.
  3. Choose Edit settings, add admin in Roles, and save.
  4. Ask the user to log out and log in again so Netlify issues a new JWT containing the role.

The admin role grants CTA and article management. Account invitations, role changes and deletions are separately restricted to the project owner configured by VF_ADMIN_EMAIL.

Important: this is a Netlify Identity application role, not the Owner/Developer role used for access to the Netlify team dashboard.
