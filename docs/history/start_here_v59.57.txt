VEILFARERS PORTAL v59.57 — START HERE
=====================================

PURPOSE
-------
This release rebuilds the visual presentation of the entire Character Creator using the approved dark navy, gold, heraldic interface direction. It also completes the Affiliation crest set with House Amaranth and Independent.

DEPLOY
------
1. Create a branch from the current production baseline.
2. Replace the repository contents with the contents of VeilFarers_Portal_v59.57.zip.
3. Do not copy files from older portal ZIPs over this release.
4. Commit the package contents and open a Deploy Preview.
5. No Firestore Rules deployment is required for this visual release.
6. No new Netlify environment variable is required.
