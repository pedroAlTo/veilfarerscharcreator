VEILFARERS PORTAL v59.55 — START HERE

BASE PACKAGE
This hotfix continues from v59.54. The user-revised Downloads manifest and five bundled PDFs remain unchanged.

DEPLOY
1. Create or use a clean test branch.
2. Extract VeilFarers_Portal_v59.55.zip.
3. Copy the CONTENTS of the ZIP into the repository root; index.html must remain at the root.
4. Commit with GitHub Desktop or your normal signed workflow.
5. Push and wait for all Netlify checks.
6. Open the Deploy Preview and perform a hard refresh.
7. Sign out and back in before testing table operations.

IMMEDIATE ACCEPTANCE
1. Connect Keeper Tool as the table owner.
2. Send a plain text note to all players.
3. Send a private note to one selected player; another player must not receive it.
4. Send a note containing pasted comma- or tab-separated table data.
5. Delete the sent note.
6. Confirm Network shows 200 for sendHandout/readSession/deleteHandout.
7. If an error appears, copy the visible Reference value and locate it in Netlify → Logs & Metrics → Functions → table-api.

BROWSER EXTENSION MESSAGE
`A listener indicated an asynchronous response...` is normally emitted by a browser extension message channel. It is separate from the VeilFarers API. The relevant application signal is the `/api/table-api` status and its request reference.
