VEILFARERS PORTAL v59.64 — START HERE
=====================================

RELEASE PURPOSE
---------------
v59.64 fixes Massive damage-pool scaling, the permanent 3D-roll lock caused by
closing the dice box during resolution, and Keeper Notes delivery/visibility.

DEPLOY
------
1. Extract VeilFarers_Portal_v59.64.zip.
2. Replace the repository/publish-root contents with the extracted contents.
3. Confirm _headers, netlify.toml, player-tool.html and assets/ are at root.
4. Commit and push to a test branch.
5. Test the Netlify Deploy Preview and hard-refresh the tools.

PRIORITY TESTS
--------------
1. Massive final 2d8+3:
   - four d8s roll;
   - highest two are kept;
   - +3 is applied once.
2. Massive critical final 4d8+3:
   - eight d8s roll;
   - highest four are kept.
3. Close the 3D dice box while dice are resolving, then roll again repeatedly.
   No "A dice roll is already resolving" error may occur.
4. Connect Keeper Tool as table owner and send an all-player note.
   Confirm it opens in connected Player Tool within approximately 1.25 seconds.
5. Scroll Keeper Console and confirm Player Notes remains visible.
6. Send a private note and verify that only the intended player receives it.
7. Verify /data/deploy-version.json reports v59.64 and the CSP still includes
   'wasm-unsafe-eval'.

NO MANUAL CLOUD CHANGE

No Firebase migration, Firestore Rules deployment or environment-variable change
is required for v59.64.
