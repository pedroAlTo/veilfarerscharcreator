VEILFARERS PORTAL v59.52 — START HERE
=====================================

PRIMARY DEPLOY ARTIFACT
-----------------------
VeilFarers_Portal_v59.52.zip

DEPLOY TO TEST BRANCH
---------------------
1. Preserve the current v59.51 artifact and active Firestore Rules.
2. Extract the v59.52 ZIP locally.
3. Replace the branch contents with the CONTENTS of the ZIP. index.html must remain at repository root.
4. Commit with GitHub Desktop and push to a test branch.
5. Wait for all Netlify checks and Deploy Preview build steps.
6. Hard-refresh the preview, sign out and sign back in on every test account.

REQUIRED VAULT TEST
-------------------
1. Create/import at least three completed characters under one account.
2. Account must show all three and exactly one ACTIVE badge.
3. Set another active character, refresh, and verify the same selection in Account/navigation/Player Tool.
4. Repeat from another browser session for the same account.
5. Trash the active character and verify one remaining record becomes active.
6. Restore it; unrelated characters must remain intact.

REQUIRED TABLE COMMUNICATION TEST
---------------------------------
Use three distinct accounts:
- Keeper/owner in Table A;
- Player A1 in Table A;
- Player A2 in Table A;
- optionally the Keeper or a fourth account with a player in Table B.

1. Send a note to Player A1 only. A1 receives it; A2 and Table B do not.
2. Send a note to all Table A players. A1 and A2 receive it; Table B does not.
3. Change A1's active character and repeat the private note; account UID targeting must still work.
4. Select KEEPER ONLY and roll. No Player receives the roll and no public table-history record is created.
5. Select BROADCAST and roll. Only Table A receives it.
6. Change to Table B and verify private Keeper history is not mixed between tables.

KEEPER UI TEST
--------------
- Compare desktop visual hierarchy with Player Tool.
- Check fixed Keeper Console, tabs, panels, cyan states and amber actions.
- Open the Player Note modal; it must appear above navigation and console.
- Test keyboard focus and responsive/mobile console placement.
