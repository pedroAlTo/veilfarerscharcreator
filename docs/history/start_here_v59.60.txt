VEILFARERS PORTAL v59.60 — START HERE
=====================================

RELEASE PURPOSE
---------------
v59.60 is a focused 3D dice loading hotfix for Netlify/Linux deployments.

ROOT CAUSE
----------
The bundled world renderer imports `./Dice.min.js`, but v59.59 only contained
`assets/3d-dice/dice.min.js`. Windows commonly treats those names as equivalent;
Netlify's Linux filesystem does not. The module request therefore returned 404
and the 3D renderer never initialized.

DEPLOY
------
1. Replace the repository contents with this package.
2. Commit and push to a test branch.
3. Let Netlify create a Deploy Preview.
4. Hard-refresh Player Tool once after the deploy.

PRIORITY ACCEPTANCE TESTS
-------------------------
1. Open Player Tool on the Netlify Deploy Preview.
2. Enable 3D dice and make a Duality roll.
3. Confirm Hope and Fear dice appear, settle once, and preserve the rolled values.
4. Roll damage and verify the red Damage theme loads.
5. Test Plain, Tech and Crystal themes.
6. In DevTools Network, confirm `assets/3d-dice/Dice.min.js` returns HTTP 200.
7. Confirm no `Failed to fetch dynamically imported module` or Dice.min.js 404 appears.

ROLLBACK
--------
Redeploy v59.59. No database, Firebase or rules migration is involved.
