VEILFARERS PORTAL v59.61 — START HERE
=====================================

RELEASE PURPOSE
---------------
Restore the Ammo WebAssembly physics runtime used by Player Tool 3D dice on Netlify.

ROOT CAUSE
----------
The production Content Security Policy blocked WebAssembly compilation because script-src
contained neither 'wasm-unsafe-eval' nor the broader 'unsafe-eval'. The Ammo file was present;
the browser rejected its execution before initialization.

DEPLOY
------
1. Replace repository contents with VeilFarers_Portal_v59.61_3D_Dice_WASM_CSP_Hotfix.zip.
2. Push to a test branch and use a Netlify Deploy Preview.
3. Hard-refresh Player Tool.
4. Inspect the HTML document response header and verify script-src includes 'wasm-unsafe-eval'.
5. Test standard, Duality and Damage 3D rolls.

NO CLOUD MIGRATION
------------------
Do not deploy Firestore Rules. No Firebase migration or environment-variable change is needed.

ROLLBACK
--------
Redeploy v59.60. The standard dice fallback remains available, but 3D WASM physics will be blocked.

DOCUMENTATION
-------------
Read GITHUB_DEPLOY_SUMMARY_v59.61.md and PORTAL_HANDOVER_v59.61.md.
