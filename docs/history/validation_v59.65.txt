----------------------------
PASS  Every visual roll/add operation creates an active controller and unique token.
PASS  Renderer completion races an explicit cancellation Promise.
PASS  Manual close invokes cancelActiveRoll('user-dismissed').
PASS  Pending DiceBox rollCollectionData resolvers are settled before clear().
PASS  Ammo/Babylon world clear is executed for the dismissed visual operation.
PASS  Fallback values preserve requested quantity and die sides.
PASS  Dismissed operations resolve with cancelled=true rather than throwing.
PASS  finally releases activeRollController and rollPending.
PASS  showResults respects userDismissed and does not reopen the closed HUD.
PASS  The 14-second safety timeout remains for genuine renderer failures.
