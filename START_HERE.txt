VeilFarers Portal v59.15
=======================

Deploy the contents of this folder directly to Netlify. This build replaces v59.14.

Player Tool Firestore save fix
------------------------------
Player Tool no longer fails to join or autosave a table when legacy imports,
custom weapons, or optional character fields contain JavaScript `undefined` values.
Firestore does not accept `undefined` in document data.

The fix uses three layers:

1. Firestore is initialized with `ignoreUndefinedProperties: true` before use.
2. Every Player Tool write is recursively normalized before it reaches Firestore.
   Undefined object properties are omitted; undefined array positions become null.
3. Optional weapon `burden` values now normalize to null during import and hydration.

The normalizer preserves Firestore-native values such as FieldValue.arrayUnion,
Timestamp, GeoPoint, and DocumentReference.

Session connection hardening
----------------------------
- Leading and trailing whitespace is removed from table names before the Firestore
  document reference is created.
- The table metadata write is awaited before the interface reports Connected.
- Autosave clears a previous Save error after the next successful write.
- Undefined field paths are logged to the browser console for diagnostics without
  exposing character data to other services.

Keeper Tool
-----------
Keeper Tool now enables the same Firestore SDK option for undefined optional fields.
Its existing real-time session behavior and document schema are unchanged.

Deploy Preview checks
---------------------
1. Open Player Tool with a character imported from an older JSON file.
2. Add or equip a custom weapon without a burden value.
3. Join a table whose entered name contains leading or trailing spaces.
4. Confirm the UI reports Connected and no unsupported-field error appears.
5. Edit HP, Stress, Experiences, equipment, and weapon loadout; confirm autosave.
6. Open a second Player Tool and Keeper Tool on the normalized table name.
7. Confirm character updates, roll callouts, Fear, Spotlight, and roll history sync.
8. Confirm an earlier Save error disappears after a successful save.
