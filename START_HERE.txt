VeilFarers Portal v59.35

RELEASE PURPOSE
---------------
Fix the augmentation-manager React crash, remove tool-card character images from the welcome page while preserving its background, and retain the canonical armor, augmentation and gear loadout managers.

------------

/creator.html         Character Creator

/admin.html           Admin (admin role required in production)

ONLINE DEPLOY
-------------
Deploy the contents of this folder to Netlify. Keep the existing Firebase environment variables and set:

FIREBASE_PUBLIC_TABLE_DIRECTORY=false

Keeper/Admin routes use Netlify Identity role redirects. Verify roles in a Deploy Preview before replacing production.

SECURITY POSITION
-----------------
This package preserves the prior public-launch hardening baseline. Private campaign data is still not production-secure until Firestore Security Rules, authenticated table membership and App Check are completed.

Read SECURITY_PUBLIC_LAUNCH_v59.27.md before enabling public cloud-table traffic.

LOCAL TESTING
-------------
Read LOCAL_TESTING.md. Copy local/.env.local.example to local/.env.local, fill local Firebase values if needed, then run START_LOCAL_WINDOWS.bat or local/start-local.sh.
