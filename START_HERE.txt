VeilFarers Portal v59.7
======================

Deploy the contents of this folder directly to Netlify. This build replaces v59.6.

Canonical navigation
--------------------
- portal.js is the only site-level navigation layer.
- The obsolete Character Sheet Player/Keeper link strip has been removed.
- Player Tool and Keeper Tool retain their functional character/session controls, but no separate site navigation.

Digital Character Sheet
-----------------------
The toolbar has been reduced to the controls that are specific to the sheet:
- Guided Fill, Random Character and Reset.
- View and zoom controls.
- JSON load/save.
- Visual PDF and physical PDF export.
- Sleeping/Awakened path switch.
- Sync Draft, injected by sheet-bridge.js, imports the current canonical Character Creator draft.

The embedded Creator button, Setup/Play Mode section, Downloads/Feedback section and sheet-local Account section remain in the DOM but are hidden and marked as reserved controls. They can be re-enabled later without reconstructing the underlying logic.

Downloads
---------
Downloads now contains:
- Four VeilFarers 11.1 RC2 PDF candidates.
- The retained editable two-page physical character-sheet PDF.

The fillable sheet contains 186 form fields and remains at:
/download/veilfarers_charsheet_fillable.pdf

Cohesion changes
----------------
- Shared portal navigation surface, border, active state and spacing.
- Shared module page rhythm for headers, panels, fields and actions.
- Character Sheet toolbar aligned with the same gold/dark portal surface system.
- Duplicate navigation and account controls removed from the visible sheet workflow.

Services
--------
- Netlify Identity: account login, roles, character vault, and Keeper Tool access.
- Firebase Authentication/Firestore: real-time Player Tool and Keeper Tool table sessions.
- Firebase browser configuration: served at runtime by /api/firebase-config from Netlify environment variables.

Required Netlify checks
-----------------------
1. Confirm the canonical navigation appears once on Character Sheet, Player Tool and Keeper Tool.
2. Confirm the Character Sheet toolbar does not show Creator, Mode, Downloads, Feedback or Account controls.
3. Confirm Sync Draft imports the current Creator draft.
4. Confirm both editable and print-ready PDF exports still work.
5. Confirm Downloads lists the fillable physical character sheet.
6. Confirm Netlify Identity login status remains available from the canonical navigation.
7. Confirm Player/Keeper Firebase sessions and roll callouts remain operational.

Validation
----------
Read VALIDATION_v59.7.txt for automated static, dependency, data and PDF-form checks.
Identity, Firebase, generated PDFs and responsive browser rendering must still be checked on a Netlify Deploy Preview.
