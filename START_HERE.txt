VeilFarers Portal v59.43

RELEASE PURPOSE
---------------
Extend Player and Keeper live play with canonical armor automation, resource-aware augmentation use, playable drone sheets, synchronized drone signal controls, and an OPEN/CLOSED table directory with protected passwords.

PLAYER TOOL
-----------
- New characters start at full HP, 2 Hope/Effort and full Resolve.
- Active armor applies its thresholds, armor slots and supported modifiers.
- Augmentation activation automatically marks Stress or spends Hope/Effort.
- Drone tabs use canonical frames/modules, have no Hope/Effort/Resolve/Stress tracks, and start at full HP and armor.
- A drone never owns Spotlight; its sheet displays and changes the current character Spotlight with the same lantern component used in the tabs.
- Drone Signal uses Stable, Unstable and Lost and can be changed by players or the Keeper.

TABLES AND PASSWORDS
--------------------
- Table discovery is enabled unless FIREBASE_PUBLIC_TABLE_DIRECTORY=false is set.
- The directory clearly labels OPEN and CLOSED tables.
- Creating an open table requires an explicit warning confirmation in Player Tool.
- Passwords are stored as salted PBKDF2-SHA256 records, never as plaintext.
- A password can only be added or changed after the user has successfully connected to that table.

SECURITY BOUNDARY
-----------------
The password is a client-side entry gate and protects against casual access. It is not a substitute for Firestore Security Rules, authenticated table membership or App Check. Read SECURITY_TABLES_v59.43.md before treating cloud table data as private.

LOCAL TESTING
-------------
Read LOCAL_TESTING.md. Table discovery is enabled by default locally unless FIREBASE_PUBLIC_TABLE_DIRECTORY=false is explicitly set.
