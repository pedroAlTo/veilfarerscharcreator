VEILFARERS PORTAL v59.56 — START HERE

BASE PACKAGE
v59.56 continues from v59.55 and changes only the Character Creator Affiliation card presentation plus the new crest assets and release documentation.

DEPLOY
1. Create or use a clean test branch.
2. Extract VeilFarers_Portal_v59.56.zip.
3. Copy the CONTENTS of the ZIP into the repository root; index.html must remain at the root.
4. Commit through GitHub Desktop or the normal signed workflow.
5. Push and wait for Netlify checks.
6. Open the Deploy Preview and hard-refresh.

IMMEDIATE ACCEPTANCE
1. Open Character Creator.
2. Navigate to Step 6 — Affiliation.
3. Confirm 13 canonical cards remain available.
4. Confirm supplied crests appear for Church of the Eternal Veil, Explorers' Guild, Free Fleet, Joric, Kurogane, Solari, Valerius, Volkov, Solara Compact, Stellar Commerce Guild and Kaelen.
5. Confirm House Amaranth and Independent show monogram fallbacks.
6. Test selection and Next on desktop and mobile.
7. Import an existing character and confirm its affiliation is still selected.

CANON BOUNDARY
Starborn Collective and Spire of Verita art is included as future-ready assets but no Affiliation choices were added because the current canonical Affiliation dataset does not contain those entries.

FIRESTORE RULES
No Rules change is required. The included firestore_v59.56.rules is the unchanged coordinated baseline.
