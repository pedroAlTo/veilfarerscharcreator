VeilFarers Portal v59.8
======================

Deploy the contents of this folder directly to Netlify. This build replaces v59.7.

Player Tool backgrounds
-----------------------
The deployment now includes the two background assets referenced by Player Tool:
- /assets/bg-spacestation.webp
- /assets/bg-panels.webp

The background selector and existing local preference key remain unchanged.

Character Creator flow
----------------------
- A single fixed Back/Next dock remains visible in the lower-right corner during all nine creation steps.
- Next is disabled until the active step is complete.
- Ailuran selection opens the two required Sub-Strain options in a custom overlay.
- Clicking outside the Ailuran overlay cancels Ailuran selection.
- Choosing a class opens its subclass choices in the same viewport-level overlay.
- Clicking outside the subclass overlay cancels the selected class.
- The old inline Sub-Strain and subclass regions remain as compatibility mounts but no longer create a second scroll-dependent workflow.

Traits
------
The fixed +2, +1, +1, +0, +0, -1 array now supports:
- Select a value, then a trait.
- Select a trait, then a value.
- Select two assigned traits to swap values.
- Drag an available value onto a trait.
- Assignment progress and Clear assignments.

Experiences
-----------
Starting characters now use three Experiences at +2. The third Experience is included in:
- Creator state.
- Draft persistence.
- JSON save/load and migration of older two-Experience drafts.
- Step validation.
- Generated Creator character sheet.

Services
--------
- Netlify Identity: account login, roles, character vault, and Keeper Tool access.
- Firebase Authentication/Firestore: real-time Player Tool and Keeper Tool table sessions.
- Firebase browser configuration: served at runtime by /api/firebase-config from Netlify environment variables.

Required Deploy Preview checks
------------------------------
1. Open Player Tool Settings and select both restored backgrounds.
2. Select Ailuran, cancel by clicking the overlay backdrop, then select it again and complete a Sub-Strain.
3. Select a path and class; verify subclass options open without scrolling.
4. Complete traits using both click orders and at least one swap.
5. Enter three Experiences, save JSON, reload it, and verify all three remain.
6. Complete a character and verify all three Experiences appear on the generated sheet.
7. Regression-test Netlify Identity, Firebase sessions, roll callouts and PDF exports.

Validation
----------
Read VALIDATION_v59.8.txt for static and headless interaction checks.
Identity, Firebase and Netlify runtime behavior must still be tested on a Deploy Preview.
