VeilFarers Portal v59.17

Deploy the contents of this folder to Netlify.

This build is based on v59.16 and fixes two production regressions:
- Table connections failed because normalizeSessionKey was referenced but not defined.
- The official 3D dice module used an invalid asset URL and did not parse the v1.1 result format correctly.

Retained without change:
- Corebook 11.1 RC3.1 and all other PDFs.
- Firestore undefined-value sanitization.
- Weapon Trait and feature resolution.
- Six simultaneous callouts, Time Travel, sound, volume and mute.
- Hope/Fear/Damage/Neutral VeilFarers dice themes and DisplayResults attribution.

Required Netlify configuration remains unchanged:
- Netlify Identity enabled.
- Firebase environment variables configured.
- /api/firebase-config Function deployed.
- Firebase anonymous authentication enabled.
