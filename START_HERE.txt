VeilFarers Portal v59.10
=======================

Deploy the contents of this folder directly to Netlify. This build replaces v59.9.

Hope / Effort alternative payments
----------------------------------
Player Tool now follows the canonical resource rule that any ability with a Hope cost may instead be paid with the same amount of Effort.

This applies to executable actions generated from:
- Ancestry Gifts;
- Class Features;
- Community Features;
- Hope Features;
- Domain Cards.

Both payment options remain visible. Each button is independently disabled when the character lacks the required resource. The selected payment is deducted before the action resolves.

Roll records
------------
Feature and Domain Card activations record the selected Hope or Effort payment in:
- the local Player Tool Roll History;
- Firebase table-wide roll callouts;
- the shared session roll history.

Existing mechanics retained
---------------------------
- Operational multi-weapon arsenal and active-weapon switching.
- Reliable, Accurate, Heavy, Massive, Brutal and Paired automation.
- Structured weapon effects, resistance/DC notes and damage details.
- Canonical 11.1 RC2 datasets.
- Netlify Identity accounts and roles.
- Firebase real-time Player/Keeper sessions.

Required Deploy Preview checks
------------------------------
1. Import a character whose Ancestry Gift costs Hope.
2. Verify separate Hope and Effort action buttons are shown.
3. Activate with Hope and verify Hope decreases by the stated amount.
4. Activate with Effort and verify Effort decreases by the stated amount.
5. Verify insufficient-resource buttons are disabled independently.
6. Activate a Domain Card using both payment methods.
7. Confirm the selected resource appears in the local history and on another browser connected to the same Firebase table.

Validation
----------
Read VALIDATION_v59.10.txt for automated checks.
Identity, Firebase broadcasting, responsive layout and cross-browser interaction must still be tested on a Netlify Deploy Preview.
