VeilFarers Portal v59.14
=======================

Deploy the contents of this folder directly to Netlify. This build replaces v59.12.

Player Tool information hierarchy
---------------------------------
Sleeper Actions and Resolve Moves are now separate compact panels. On wide screens they appear side by side; on narrow screens they stack. Both are collapsed by default and use VeilFarers + / - controls rather than browser-native disclosure widgets.

Ancestry Gift, Class Feature, Community Feature and Effort/Hope Feature cards follow the same pattern: title and short description remain visible, while the complete rules and executable buttons appear after expansion.

Resolve Moves
-------------
Player Tool loads Resolve Moves from /rules-data/core/resolve-moves.json. It shows the two Class Moves plus the matching Subclass Move.

- Fixed-cost moves spend the printed amount.
- “Spend and roll” moves roll Resolve Dice (d4).
- “1+” moves use the in-app dialog to choose how many available Resolve Dice to spend.
- Results and move text are written to local Roll History and Firebase table callouts.

The dataset contains the current moves for every Sleeping class. Soldier and Vanguard use the approved consolidated review draft.
