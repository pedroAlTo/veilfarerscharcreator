Veilfarers Character Creator - Netlify Identity + Google Login

What changed
- Online Vault now presents Google as the primary sign-in option.
- Email login, account creation, password recovery, logout, and refresh remain available through Netlify Identity.
- Save buttons are disabled until the user is signed in, reducing failed actions.
- Status and vault messages use live regions for clearer feedback.

Netlify setup required
1. Deploy this folder to Netlify.
2. In Netlify, open the project.
3. Go to Project configuration -> Identity and enable Identity if it is not already enabled.
4. Go to Identity -> Registration -> External providers.
5. Add Google.
6. Choose either Netlify's default provider or configure a branded Google OAuth client.
7. If Registration is set to Invite only, invite users before they can register, including Google users.

Notes
- Google sign-in does not require the email confirmation step that email/password signup uses.
- The vault stores character JSON in the signed-in user's Netlify Identity metadata. Local storage and Export JSON still work as backup/offline options.
- Public share links require a server database; this static version uses Copy JSON / Import JSON for portable sharing.
