VEILFARERS PORTAL v59.62 — START HERE
=====================================

RELEASE PURPOSE
---------------
v59.62 prevents Keeper Tool startup from depending on Character Vault and adds safe,
actionable Firebase Admin diagnostics. It includes the v59.60 exact-case 3D module fix
and the v59.61 WebAssembly CSP fix.

DEPLOY
------
1. Deploy the complete contents of VeilFarers_Portal_v59.62_Keeper_Firebase_Admin_Hotfix.zip.
2. Confirm Netlify bundles the functions under netlify/functions.
3. In Netlify environment variables, verify FIREBASE_SERVICE_ACCOUNT_JSON contains the
   complete service-account JSON and is available to Functions in the deployment context.
4. Never commit or expose this value.
5. Trigger a fresh deploy after changing the variable.
6. Sign out/in and hard-refresh Keeper Tool.

PRIORITY ACCEPTANCE
-------------------
1. Open /keeper-tool.html while signed in.
   - Campaign selection appears.
   - No /api/character-vault request is generated by Keeper startup.
2. Create/load/export a local Keeper campaign without connecting to a cloud table.
3. Verify /api/table-api action=list returns 200 with valid server credentials.
4. Verify /api/character-vault action=list returns 200 on pages that use Vault.
5. Verify Player Tool 3D dice still load Dice.min.js and Ammo WASM under CSP.

EXPECTED CONFIGURATION ERROR
----------------------------
If FIREBASE_SERVICE_ACCOUNT_JSON is absent or invalid, cloud endpoints now return 503
with a safe FIREBASE_ADMIN_* code. Keeper local campaign UI should still open. The
credential must be fixed in Netlify; the public FIREBASE_API_KEY cannot replace it.

NO MIGRATION
------------
No Firestore Rules deployment, collection migration or stored-data migration is required.
